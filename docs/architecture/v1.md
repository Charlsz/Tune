# Terra — Arquitectura v1

**Versión:** 1.0  
**Fecha:** 2026-08-17  
**Basado en:** [Primer Informe](../PrimerInforme.md) — sección 5

## Visión general

Terra implementa una arquitectura MLOps modular para gestionar el ciclo de vida de modelos geoespaciales basados en **Prithvi-EO-2.0**, integrando gestión de datasets, fine-tuning con **TerraTorch**, experiment tracking y model registry con **MLflow**, evaluación automatizada, despliegue containerizado e inferencia mediante **API REST**.

## Separación de responsabilidades

Siguiendo el primer informe (sección 5):

- **Componentes específicos de tarea:** dataset, config YAML, métricas, endpoints de inferencia.
- **Componentes generales de infraestructura:** pipeline, MLflow, API, contenedores, scripts de despliegue.

Esta separación permite incorporar una segunda tarea (Flood Detection) cambiando principalmente dataset, configuración y métricas, sin modificar el núcleo MLOps.
